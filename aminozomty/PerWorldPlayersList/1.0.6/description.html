PerWorldPlayersList

A PocketMine-MP plugin that will only show players that are in the same world on the player list menu. This plugin will be very useful if there are many players on your server.

Features

  • Shows players in the players list that are only in the same world as you
  • adding config (Coming soon)

How to Install

  1. Download the plugin (.phar)
  2. Put the .phar in the plugins folder
  3. Start or restart your server
