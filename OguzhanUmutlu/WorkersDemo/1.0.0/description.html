WorkersDemo

A plugin that adds worker entities to minecraft.

  • Workers does things that players does such as mining wood/stone etc.

How to use?

  • You can get them using /give
  • Usage: /give spawn_egg:285 - 287
  • 285: Miner
  • 286: Item grabber
  • 287: Lumberjack
