ComplexPets


A plugin that adds pets to game made by OguzhanUmutlu for PocketMine-MP.

Command

  • Simply type /pets and summon your favorite animal!

Features

  • No database
  • Pet riding! NEW
  • Pets can sit
  • Custom pet names
  • Pet inventories
  • Advanced follow AI for pets
  • Converting pets to spawn eggs
  • Change pet's visibilities
