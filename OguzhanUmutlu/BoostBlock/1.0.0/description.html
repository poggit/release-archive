BoostBlock

Adds boost blocks to PocketMine-MP.

These boost blocks can be defined to a block or a position.

You can configure the boost amount in the config.yml.

Command

/boostblock - Manage boost blocks with a single command!

API

use OguzhanUmutlu\BoostBlock\BoostBlock;

BoostBlock::setBoostBlock($player, new AngryVillagerParticle($player));

BoostBlock::unsetBoostBlock($player);
