[Description]

Easily customize your server.

By installing this plugin you will be able to customize your server MOTD.

Add unlimate & colorful & changeable MOTD for your server.

[Setup]

  1. Put phar from Poggit into plugins folder
  2. Edit the Settings.yml file of plugin in plugin_data/RandomMOTD
  3. you can disable or enable plugin by set start-working: to false or true
  4. You can set colorful messages in Settings.yml
  5. You can change RepeatTime of MOTD in Settings.yml

Hope you enjoy using plugin.
