[Description]

Repair the items in your hand.

Players can repair items in their hand with Money or Xp.

You can set paymentmode to (Xp) or (Money).

You can set special price for repair enchanted items.

You can set Cooldown for when player repair items.

[How to Setup?!]

  1. Put phar from Poggit into plugins folder
  2. Edit the config.yml file of plugin in plugin_data/EasyRepairItems
  3. if you set XP: false and MONEY: true, players can repair their items with Money.
  4. if you set MONEY: false and XP: true, players can repair their items with Xp.
  5. if you set Cooldown: false , Cooldown will not working.
  6. you can set timer for Cooldown in Config.yml Timer: 10 , it means player can repair items every 10 second.
  7. You Can Repair Your Damaged Item in Your Hand With Command:
  • /repair
    • Permission: EasyRepairItems.command
    • Default: Op

Permission Is For Repair Items Free.

set this permission to VIP players.
