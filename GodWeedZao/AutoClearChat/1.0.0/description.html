[Description]

Clear chat in your server easily!

You can clear chat in your server with timer or handly with command!

[Usage]

  1. Put phar from Poggit into plugins folder
  2. Edit the config.yml file of plugin in plugin_data/AutoClearChat
  3. you can set Auto-Clean: false to doesn't Clear Chat Automatically!
  4. You Can Clear chat Handly with Command:
  • /cc
    • Permission: gw.clear.chat
    • Default: Op

I hope you enjoy using this plugin!
