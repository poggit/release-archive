Information

A plugin-(API), it show User's informations(IP,OS,Device Name). SHOW the OS over the head of players (Can be disabled in config.yml) Version 0.0.7

Command

Only 2 commands: /seedevice [player] => To Show User information or himself information /fakeos => To change the name of your OS in-game

Permission

Only player with the permission"SeeDevice.command." and op can use there commands

API

Two main function getUos, getUsd to call them make sure you are "including" use SeeDevice\SeeDevice; and make $os = SeeDevice::getInstance()->getUos($player);
