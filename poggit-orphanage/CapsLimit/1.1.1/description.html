Intro

This plugin is able to detect the amount of caps (uppercase) used by players, and block messages sent by players if they exceed the limit set in config.yml

Features

  • SimpleAuth Support
  • Two modes available!
  • Exception Permission Node

Commands

/capslimit <value> - Set the caps can be used through command

Permissions

  • capslimit.set - Permission to use /capslimit (Default OP)
  • capslimit.exception - Exception to use caps (Default OP)
