SlotsPlus is a simple plugin to get unlimited player slots or fake your player slots.

NOTES:

  • The plugin will NOT work if you enable both unlimited slots and fake players. Only enable one at a time.
  • This plugin will NOT add fake players to your server. It'll only add fake filled-up slots.

Features

  • Ability to fake your server's player slots.
  • Ability to get unlimited player slots on your server.

Setup

Navigate to the config.yml file (Found at resources/config.yml) and edit it to satisfy your needs. If you want unlimited player slots, Set the "unlimitedSlots" value to true. If you don't, Set it to false. If you want to fake your player slots, Set the "fakePlayers" value to true and set the "fakeSlots" value to the number of fake slots you want. If you don't want to fake your slots, Set it to false.
