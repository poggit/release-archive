A Custom Enchants plugin based off of AvengeTechs enchants, these enchants are very balanced and different than PiggyCE.

Commands

Commands Usages
at enchant Enchants the item the specified player is holding. Usage: /at enchant (player) (enchant) [level]
at list Sends a categorized list of the available enchants.

Permissions

atenchant.command - Permission to use the command /at enchant
