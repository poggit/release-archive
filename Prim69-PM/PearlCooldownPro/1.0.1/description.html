This is a configurable plugin that lets you add a cooldown timer between throwing enderpearls. You can set the cooldown message and timer in config.

DISCLAIMER: The current pearl cooldown plugin already on Poggit hasn't been updated in a year, when people left click a block it counts as a thrown pearl, when people right click directly onto a block it counts as a thrown pearl (setting the timer and cancelling the pearl), it basically doesn't work. With this plugin all those issues are fixed and there are also no known issues.

Please report any issues to the Github, or any suggestions you may have.

Coming soon: more ways in config to show the timer, boss bar, xp bar, etc.
