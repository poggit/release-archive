About

This plugin allows you to record and re-watch a players movements!

Real entities would lag the server so Replay uses fake ones!

Thanks to BoomYourBang#0001 for helping me with the weird fake entity stuff!

Video showcase: https://youtu.be/fWvxrB-byGc

Commands

Commands Usages
/replay start Starts recording a players' movements
/replay save Stops the recording and saves it
/replay watch Lets you watch the saved recording
/replay delete Delete the saved recording
/replay list Lists all the saved recordings

Permissions

replay.command: Allows you to use /replay.
