What is this?

This plugin let's you lock your trapdoors, doors and chests (at the moment only single chests)

How to use this plugin?

  • Place an iron door and execute the command /lock , then you will have to touch the door you wanted to lock. When the door is locked you will receive a key.
  • If you want to unlock a door you will have to execute /unlock and then touch the door. You can also use /unlock so you don't have to touch the door.
  • Doors can only be unlocked by people with the appropriate permission. This plugin was made for roleplay purposes, so a normal player will not be able to /unlock a door. The play can however open a door with a key.

Permissions

Permissions that you can use.

lms.lock: Allows the user to lock a door
lms.unlock: Allows the user to unlock a door
lms.makekey: Allows the user to make a key for any door.
lms.break: Allows the user to break any locked door.
