Information

This plugin allows you to enhance when a player joins your server through the easy to use commands and config. This plugin is for anyone to use.

  • Credits: BlazeTheDev

How to use

How to install:

  1. Download the plugin's phar.
  2. Drop the plugin's phar into the /plugins folder in your server.
  3. Restart your server so that the plugin will be enabled.

How to use: Go in-game and when joining you should see all of the enhancements you have enabled within the config.

  • For further info on how to use this plugin go to BlazinJoin Wiki.
