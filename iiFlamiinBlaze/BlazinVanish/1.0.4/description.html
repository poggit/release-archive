Information

This plugin allows you to vanish from other players through configs. This plugin is for anyone to use. If you have any issues with the plugin, please make an issue here.

  • Credits: BlazeTheDev

How to use

How to install:

  1. Download the plugin's phar.
  2. Drop the plugin's phar into the /plugins folder in your server.
  3. Restart your server so that the plugin will be enabled.

How to use: Go in-game and run the command /vanish to vanish from people's view.

  • For more info about how to use the plugin go to the BlazinVanish Wiki.
