Information

This plugin allows you to configure messages and commands that will send at a certain interval of time! Anyone is allowed to use this plugin.

  • Credits: BlazeTheDev

How to use

How to install:

  1. Download the plugin's phar.
  2. Drop the plugin's phar into the /plugins folder in your server.
  3. Restart your server so that the plugin will be enabled.

How to use: Go in-game and eventually you will be able to see the messages and commands you set in the config.

  • For further info look go to BlazinBroadcasts Wiki
