Command Usage:

/playerinfo <player>

We also have a shorter command:
/pinfo <player>

Permission:

playerinfo.use - Allows the player to use the command /playerinfo

Example:

Name: Steve
IP: 127.0.0.1
OS: iOS
Model: iPhone
UI: Classic UI
GUI Scale: Maximum
Controls: Touch
HP: 20HP
Position: X: 0, Y: 0, Z: 0\
