MultiWorld

Ported MultiWorld to PocketMine-MP

Features:

  • Manage worlds (create, remove, update, ...)
  • Load / unload worlds
  • MultiLanguage support (English, Russian, German, Czech)
  • Commands works in console
  • End, Void and SkyBlock generators

Commands:

Create Command:

  • usage: /mw create [seed] [generator]
  • permission: mw.cmd.create
  • aliases: add, new, generate
  • generators: Normal, Flat, Nether

Teleport Command:

  • usage: /mw teleport [player]
  • permission: mw.cmd.teleport
  • aliases: tp

List Command:

  • usage: /mw list
  • permission: mw.cmd.list
  • aliases: ls

Help Command:

  • usage: /mw help
  • permission: mw.cmd.help
  • aliases: ?

Delete Command:

  • usage: /mw delete
  • permission: mw.cmd.delete
  • aliases: rm, del, remove

Load Command:

  • usage: /mw load
  • permission: mw.cmd.load
  • aliases: ld

Unload Command:

  • usage: /mw unload
  • permission: mw.cmd.unload
  • aliases: unld

Update Command:

  • usage: /mw update <spawn|lobby|defaultlevel> [options]
  • permissions: mw.cmd.updete
  • aliases: upte, ue

Info Command:

  • usage: /mw info
  • permissions: mw.cmd.info
  • aliases: i

Permissions:

  • Default Permissions: mw
    • All Commands Permissions: mw.cmd
