EasyWing

Wing particle plugin for Pocketmine-MP

Feature

  • Add and custom wing in config
  • FormAPI Support

 0: space

 4 : Red Dust

 x: Redstone
 f: Flame
 b: Blue Flame
 h: Villager Happy
 p: Villager Angry

How to get a wing

  • Add permision to player wing.on.<wing name>
