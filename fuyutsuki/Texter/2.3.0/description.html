Features

  • Multi-world support
  • It is easy to add / edit / move / delete by command, it can also be added from file

Commands

General command

\ command alias
Add text /txt add /txt a
Edit text /txt edit /txt e
Move text /txt move /txt m
Remove text /txt remove /txt r
Help /txt or /txt help /txt ?

Management command

\ command argument alias
Remove all /txtadm allremove none /tadm ar
Remove texts/user /txtadm userremove <userName> /tadm ur
Remove texts/level /txtadm levelremove <worldName> /tadm lr
Info /txtadm info none /tadm i
Help /txtadm or /txtadm help none /tadm ?

ConfigurationFiles

config.yml

This file is for configuration.

  • configVersion:
    Please do not change. It is used when there is specification change.
  • language: eng
    You can change the language. Currently supported languages are jpn, eng.
  • timezone: Asia/Tokyo
    You can change the time zone. Please see here for possible values.
    If you want to disable it please set it to false.
  • check.update: true
    You can check if there is an update.
    If you want to disable it, please set it to false.
  • can.use.commands: true
    You can set whether commands can be used in the server.
    If you want to disable it, please set it to false.
  • limit: 50
    You can limit the number of characters in FloatingText.
    ex) 50 => within 50 characters
    If you want to disable it, please set it to -1.
  • feed: 3
    You can limit the number of newlines in FloatingText.
    ex) 3 => within 3 feeds
    If you want to disable it, please set it to -1.
  • world: []
    You can specify a world where FloatingText can not be placed.
    If you do not specify it you do not need to change anything.

crfts.json

We set a FloatingText for the coordinates of the world specified in this file.

{
  "LevelName": {
    "TextName(Unique)": {
      "Xvec": 128,
      "Yvec": 90,
      "Zvec": 128,
      "TITLE": "Title",
      "TEXT": "Text(New line with #)"
    }
  }
}

fts.json

This file stores FloatingText placed by command.
It is almost the same format as crfts.json.

Permissions

  • texter.commands.txt - Add, delete and update FloatingText with the txt command.
    defalult: true
  • texter.commands.txtadm - Use the administrator command txtadm command.
    default: op
