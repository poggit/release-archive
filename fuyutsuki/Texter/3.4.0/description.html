Features

  • Multi-world support
  • It is easy to add / edit / move / delete by command, it can also be added from file

ConfigurationFiles

config.yml

This file is for configuration.

  • language: en_us
    You can change the language. Currently supported languages are en_us, ja_jp.
  • check.update: true
    You can check if there is an update.
    If you want to disable it, please set it to false.
  • can.use.commands: true
    You can set whether commands can be used in the server.
    If you want to disable it, please set it to false.
  • can.use.only.op: false If you only want op to use the command, please set it to true.
  • limit: 50
    You can limit the number of characters in FloatingText.
    ex) 50 => within 50 characters
    If you want to disable it, please set it to -1.
  • feed: 3
    You can limit the number of newlines in FloatingText.
    ex) 3 => within 3 feeds
    If you want to disable it, please set it to -1.
  • world: []
    You can specify a world where FloatingText can not be placed.
    If you do not specify it you do not need to change anything.

uft.json

We set a FloatingText for the coordinates of the world specified in this file.

{
  "LevelName": {
    "TextName(Unique)": {
      "Xvec": 128,
      "Yvec": 90,
      "Zvec": 128,
      "TITLE": "Title",
      "TEXT": "Text(New line with #)"
    }
  }
}

ft.json

This file stores FloatingText placed by command.
It is almost the same format as uft.json.
