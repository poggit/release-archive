JoinSaveSkin

Requirement

  • gd

Enable GD Library

Uncomment extension=php_gd.dll php.ini

- ;extension=php_gd.dll
+ extension=php_gd.dll

Usage

  • Place the plugin phar in the plugins folder
  • Join the server
  • The player's skin data (png) will be saved!

plugin_data/joinskinsave/<player name>/<Y-m-d-H-i-s>.png
