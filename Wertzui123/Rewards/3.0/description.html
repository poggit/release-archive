Rewards

A (daily) reward plugin for pmmp servers. The .phar can be found on poggit.

Commands

/reward - Claim your reward
Can be edited in the config

Permissions

Commands

rewards.claim | Permission for /reward
Default: op #Other rewards.waiting.bypass | Allows you to claim a reward without waiting
Default: op

Features

Main Rewards features:

-Mostly everting can be edited throught the config
-Custom messages
-Rewards can be only claimed after a waiting periode or with the bypass permission
-Command is editable throught the config
-Multiple Commands
-Fast and free Support
-Config Updater
-And so on...
