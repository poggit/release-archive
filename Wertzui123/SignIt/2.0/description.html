SignIt is a PocketMine-MP plugin to sign items (add a lore) with a text. It is fully customizable!

Features

Main SignIt Features:

-custom sign format
-custom date format
-customizable messages
-easy to use

Command

The main command is

-/signit <text: string>

but there is also the alias

-/sign

The command can anyway be edited in the config.yml.
You can change the messages in the messages.yml.
