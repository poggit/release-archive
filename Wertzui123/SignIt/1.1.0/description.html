SignIt is a pocketmine plugin to sign items with you're name, the currently date, and a text. The best: It is fully customizable!

Features

These are all features SignIt now has:

-custom sign format
-custom date format
-bug free (If not, contact me on discord)
-fully customizable messages
-easy to use

Command

The main command is

-/signit

but there is also the alias

-/sign

And the permission for /signit is "sign.wg.command".

You can change the message wich appears on succes, or fails in the config.yml!

Config

One of the best things of SignIt is, that you can configure everything in the config.yml Just folow the notes.
