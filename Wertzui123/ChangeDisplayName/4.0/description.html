ChangeDisplayName

ChangeDisplayName lets you change your displayname (nickname).

Features

  • PurePerms support
  • Custom nickname format
  • Advanced (messages) configuration
  • Banned nicknames
  • /realname
  • /unnick

Commands

Nick

Nick yourself
Usage: /nick <nickname: string>
Aliases: nickname, changedisplayname, cdn
Permission: changedisplayname.command.nick

Realname

Find out the actual name of a nicked player
Usage: /realname <player: string>
Aliases: none
Permission: changedisplayname.command.realname

Unnick

Reset your or someone elses displayname
Usage: /unnick [player: target]
Aliases: none
Permission: changedisplayname.command.unnick

Permissions

All command permissions and:

changedisplayname.unnick.others

Lets you use /unnick on other players
Default permission state: op
