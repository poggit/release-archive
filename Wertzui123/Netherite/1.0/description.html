Netherite

This plugin adds netherite items, crafting recipes and more to your PocketMine-MP server!

Features

Done

  • Tools
  • Armor
  • Ingot and scrap
  • Items are immune to fire

WIP

  • Knockback resistance
  • Crafting Recipes

Why this plugin?

This project has some features other plugins of this kind do not suppot yet, such as crafting recipes and fire resistance of netherite items.

Icon

The icon is just a normal netherite helmet and belongs to Mojang.
