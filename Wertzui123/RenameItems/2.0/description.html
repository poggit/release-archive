RenameItems


A simple rename plugin for PocketMine-MP servers.

Commands

/rename:
Command to rename an item
Can be edited in the config.yml
Permission: renameitems.cmd.rename
/block:
Command to block an item from being renamed
Can be edited in the config.yml
Permission: renameitems.cmd.block

Permissions

Commands

renameitems.cmd.rename | Permission for /rename
Default: op renameitems.cmd.block | Permission for /block
Default: false

Other

renameitems.blockeditems.bypass | Allows you to rename blocked items
Default: false

Features

Main RenameItems features:
-Nearly everything can be adjusted in the configs
-Config updater
-Rename UI
-Items can be blocked from being renamed
