Intro

PureEntitiesX is currently in Alpha level development while PocketMine works towards reaching a stable API version. There are no stable releases of PureEntitesX at this time and changes are being made very frequently. Please bear with us as we work towards a complete efficient Mob-AI solution. Check the Wiki for more accurate information as we continue to get things updated. Please report issues and suggestions to the github repository. If you have questions about how to use this plugin, please contact us on Gitter or Discord (links below).

Contact

If you have questions, you can check the contact page in our Wiki or join the chat on Gitter and Discord!

If you are having issues, feel free to report them using the issue template provided on github. The more specific the information in your report is, the more likely we will be able to resolve your problem. If you are not sure about reporting your issue, feel free to connect with us on Gitter or Discord(links above).
