TimeStopper
If you like having your server set to always be day or night but get tired of manually setting and stopping the time on every server restart, then this plugin is for you.

Setup

Setup is very simple. If you like to keep your server stopped during daytime, then simply install the plugin and it will work immediately. If you prefer to control the specific time your server stops, then update the config.yml file for TimeStopper. Change this line Default-Time: 7000 to a time you prefer. For night try 19000.

In the Works

Additional features are being developed for future releases such as independent world time control.
