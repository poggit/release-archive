FactionMaster Bank system

This plugin is part of FactionMaster and requires installation on the server, see here for more information

Adds a bank for each faction created, for which you can add money and then use them by adding the money reward. This reward can be used in the level.yml or the config.yml

Contributing / Report

If you have a problem/bug in use, or if you have a suggestion, open an issue on GitHub and we will implement it

Translator
