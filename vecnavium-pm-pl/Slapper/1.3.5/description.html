Slapper

The new home of Slapper, the NPC plugin for PocketMine/Genisys.

We do not support Elywing or Tesseract. We recommend you use PocketMine-MP for maximum compatibility

Commands

Main level commands:

  • help: /slapper help
  • spawn: /slapper spawn [name]
  • edit: /slapper edit [id] [args...]
  • id: /slapper id
  • remove: /slapper remove [id]
  • version: /slapper version
  • cancel: /slapper cancel
  • updateall: /slapper updateall

Edit args:

  • helmet: /slapper edit helmet  
  • chestplate: /slapper edit  
  • leggings: /slapper edit leggings  - boots: /slapper edit boots  - skin: /slapper edit skin 
  • name: /slapper edit name  
  • addcommand: /slapper edit addcommand  - delcommand: /slapper edit delcommand  - listcommands: /slapper edit listcommands 
  • update: /slapper edit update 
  • block: /slapper edit block  - tphere: /slapper edit tphere 
  • tpto: /slapper edit tpto 
  • menuname: /slapper edit menuname <name/remove>
