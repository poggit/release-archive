SimpleBroadcast | v2.0.0

Automatic message system for PocketMine-MP, written in PHP-7.4 and only supports PocketMine-MP 3.0.0

Features:

  • Unlimited Messages
  • Add variables to messages
  • PocketMine-MP 3.0.0 (Only)
