AntiFrameEdit | v1.0

A plugin so that players on your server cannot use Frames.

⚡ Features:

  • Personalized messages.
  • Easy to usage.
  • Per world support.
  • Permissions for players to use the frames.
  • PocketMine-MP 3.0.0 (Only).

✒ Permissions:

Permission Description
antiframeedit.remove.bypass Allows a user to remove items in a frame.
antiframeedit.place.bypass Allows a user to put an item in any frame.
