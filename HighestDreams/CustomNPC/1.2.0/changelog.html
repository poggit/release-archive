• Added new interaction feature (Now you can interact on NPCs to run commands)

  • IMPORTANT: If you pair interaction with commands, when player interact on NPC, it run the commands list (Slap and Interact on NPCs both run the same commands as your commands list!)

  • IMPORTANT 2: If you unpair interaction with commands, when player interact on NPC, it run only defined commands for interaction! (NOT commands in NPC commands list!)
