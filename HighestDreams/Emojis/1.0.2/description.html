[Description]

Use real emojis in your pocket-mine server!

You can choose emojis to show above your head!

[Usage]

  1. Put phar from Poggit into plugins folder
  2. Edit the config.yml file of plugin in plugin_data/Emojis
  3. you can customize message & timer for emojis
  4. To see list of emojis use this command:
  • /emoji
    • Permission: Emojis.permission
    • Default: Op

Hope you enjoy using this plugin!
