ArmorEffect

Welcome to the plugin ArmorEffect created by Refaltor. It is a plugin that allows to easily add effects when the player wears armor.

  • How to install ?

Vous devez télécharger le plugin sur poggit puis le mettre dans le dossier 'plugins' sur votre serveur PocketMine-MP

https://poggit.pmmp.io/p/ArmorEffect/1.5.0

  • API:

Pour get l'API de ArmorEffect:

$api = $this->getServer()->getPluginManager()->getPlugin('ArmorEffect');
  • Functions:
$api = $this->getServer()->getPluginManager()->getPlugin('ArmorEffect');

$array = $api->getAllArmors(); // array
$armor = $api->getArmorFromString('317:0'); // array
$effects = $api->getEffectByArmor('317:0'); // array
