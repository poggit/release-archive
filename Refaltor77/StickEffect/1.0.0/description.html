L’intérêt du plugin est d’avoir une configuration infinie qui vous laisse configurer autant de stick que vous le souhaitez, les stick fonctionne en interagissant avec ! des futures mises à jour seront faites notamment pour ajouter des id avec une méta (id:meta)
