A Simple and Cutomizeable Plugin by WitherXTeam that Uses LibFormAPI and Supports PiggyCustomEnchants!

All from The same Team to bring you CustomShopUI!

Includes

This Plugin Includes:

  • Chest Kits
  • Custom Messages
  • Custom EVERYTHING
  • List and UI type Displays
  • Body and Invetory Giving Schemes
  • Suports PiggyCustomEnchants!
  • Price Per Kit!

Permissions

In the Config for Every Kit there is a permission you must add that permission to every player that needs the kit. Ex.. kit.starter is the default permission for the starter kit.
