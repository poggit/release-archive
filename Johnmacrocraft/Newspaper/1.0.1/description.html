General

Have you ever wanted to have a newspaper in your server? Or are you an administrator and looking for the best way to announce something? Then this plugin is for you! This plugin allows players to create their own newspapers. It can also be used as a bookstore plugin since it works pretty similar to it. It also supports the economy (currently only EconomyAPI), which means players can earn money by selling their works!

API

We have an API, so plugin developers can use it to manage newspapers.

Translations

Newspaper has multi-language support.
Currently, Newspaper supports the following languages:

  • English
  • Korean (한국어)
  • Japanese (日本語)

If you want to add your languages, you can submit a pull request.
When you translate, remember the following rules:

  • NEVER add words and punctuation marks that do not exist in the original. By adding these, we mean something like this:
    Original: An error has occurred
    Bad translation: An error has occurred. Please report this problem to the issue tracker.
    There is no need to translate like that; it is not what the translators are supposed to do. By doing so, you are ignoring what we intended to say.
  • NEVER translate if you DO NOT know how to translate, especially with machine translators.
  • Translate liberally if it makes the translation sound better in your language, but do not abuse it. If there is something that should be translated liberally, please ask me before doing it.
  • Translate with your language's grammar rules followed and consistency.
