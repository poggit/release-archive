theWarn

With this plugin, moderators can warn other players! The warned player where automatically banned for any days, when a player has become the full count of warns! You can customize a lot of the plugin in the messages.yml and in the banconfig.yml data. You have the control! Please send me your feedback in the comments! Thak you.

This plugin is not out of date, it is constantly being developed according to your wishes.

I hope that you have fun with this plugin!

Configuration

In the plugin folder (server/plugin_data/theWarn) you can edit all messages and other configurations of this plugin!

Commands + Permissions

/warn <playername> <reason> | thewarn.warn.cmd

/thewarnunban <playername> | thewarn.thewarnunban.cmd

bypass-permission: thewarn.cmd
