AllClaimPlotCommand

With this plugin you can instantly automatically give a plot to all online players on your server! This plugin only works with the plugin MyPlot by jasonwhynn10!

Commands + Permissions

/allclaimplot | allclaimplotcommand.allclaimplot.cmd

Bypass permission: allclaimplot.admin
