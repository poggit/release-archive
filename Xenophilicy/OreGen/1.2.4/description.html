Information

With this plugin you are able to set up custom blocks to spawn in a classic cobblestone generator rather than just plain cobblestone blocks! Each time a block spawns in a cobblestone generator, it has a chance to change to a desired block. These blocks and their probability can be changed in the plugin's config.yml file. You can black/whitelist certain worlds for OreGen to function in, or have it function in all worlds at once!

You can find a video example on YouTube → https://www.youtube.com/watch?v=Fb6llO6q9Ps

Format

Block Formatting

 Blocks:
  "Block-ID:Block-Damage": Block-Probability
  "Block-ID:Block-Damage": Block-Probability
  "Block-ID:Block-Damage": Block-Probability

Config Example

Blocks:
  "16:0": 18 # Coal Ore
  "15:0": 10 # Iron Ore
  "14:0": 8 # Gold Ore
  "21:0": 7 # Lapis Lazuli Ore
  "73:0": 5 # Redstone Ore
  "129:0": 4 # Emerald
  "56:0": 3 # Diamond Ore
