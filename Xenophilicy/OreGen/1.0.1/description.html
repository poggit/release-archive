Information

With this plugin you are able to setup ores to spawn in a classic cobblestone generator! Each time a block spawns in a cobblstone generator, it has a chance to change into a certain ore. These chances can be changed in the plugin's config.yml file under "Probability".

You can find a video example on YouTube → https://www.youtube.com/watch?v=Fb6llO6q9Ps

  • API: 3.5.0+
  • Version: 1.0.1
  • Basic Description: Generate ores inside a cobble generator!
  • Easy to edit config.yml file
  • Simple code for editing and debugging
