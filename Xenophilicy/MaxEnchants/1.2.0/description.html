Information

MaxEnchants is a simple plugin to allow servers to take full advantage of the enchanting of items. You can enchant items and blocks with any level of enchantment and they will perform just as if that was enchanted with the normal server command! You use the same command to enchant with and the exact same syntax, the only difference here is that the enchantment levels can be had up to 32767! If you want to use a different command, simply change it in the config file. You can also set things like permission nodes, max allowed levels, and the default command override to prevent two of the same command!

Config

This is the max allowed enchanting level with the command in-game Minecraft: Bedrock Edition has a maximum of 32767 enchantment levels

Max-Level: 5000

Here you can list enchantments that should have specific max levels

Custom-Max-Levels:
  4: 3500 # Projectile Protection (4) has a max level of 3500
  15: 7000 # Efficiency (15) has a max level of 7000
  22: 1 # Infinity (22) has a max level of 1

Broadcast:

Choose who should receive the broadcast messages

  SendTo:
  - "sender"
  - "console"

This is the message that will be broadcasted to the selected recipients

Message: "§a{sender} added §b{name} §alevel §b{level} §afor {target}"

Command:

This is name of the command that will be executed to use the plugin

Name: "/enchant"

This is the command's description shown in the command window

Description: "Enchant items up to level 5000"

Permission:

Choose whether to require users to have permission to execute the command

Enabled: false

This is the command's usage permission

Node: "maxenchants.enchant"

This is an option to override an existing command with the one from MaxEnchants Keeping this true makes sure that there are not two types of the same command

Override: true
