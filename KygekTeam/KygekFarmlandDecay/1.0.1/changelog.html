This release is a patch update to fix bugs and issues in previous version.

  • Now farmland won't turn into dirt when jumped if event is cancelled.
  • Now player gets teleported 0.1 blocks above to prevent being inside dirt block, as farmland blocks are lower than dirt blocks and Level->setBlock() updates the block after PlayerMoveEvent happens.
    • If you want to prevent this behavior from happening, use version 1.0.0 instead.
