RedSkyBlock

RedSkyBlock aims to be a feature rich, user-friendly SkyBlock plugin. RedSkyBlock includes many useful, built-in features that can be edited in the config.yml and with the use of some commands in-game.

Join this Discord server for support and more: https://discord.gg/qctkw5Q

How to use

  1. Drop the RedSkyBlock.phar into your server's plugin folder.
  2. Start your server.
  3. Edit the plugin settings in the config.yml.
  4. Run the /is reload command.
  5. Create a SkyBlock world with the /is createworld command.
  6. Set the SkyBlock world with the /is setworld command.
  7. Create a custom island zone with the /is setzone <1/2> and /is updatezone commands.
  8. Run the /is help command and enjoy what this plugin makes possible.
