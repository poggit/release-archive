A Pocketmine plugin that allow you to automatically update your server when a new version of Pocketmine is available. Basically the plugin is checking the latest version from the channel you choosed in your pocketmine.yml in "preferred-channel" when the server startup. If a new update is available and you have setted autoUpdate to true in your config.yml this plugin will stop all your plugins first to avoid any problems then downloading the latest version.phar and then restart your server.

WARNING : This plugin may cause your server to crash after updating and cause data loss.
