GroupsUI

Manage Groups with an UI. You need the permission for PureChat and PurePerms so that you can use the plugin without the permissions you can enter the command and the UI will open but you can#t do anything there.

Features

  • Create/Remove Groups
  • Change the nametag or the format of a group
  • Add/Remove Permission from a group
  • Change the group of an online player

Contact

Just open an issue or contact me on Discord ChampOfGames#8712.

Dependencies:

  • PurePerms
  • PureChat
