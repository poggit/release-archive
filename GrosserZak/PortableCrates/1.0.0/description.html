Description

This plugin makes sure that players open the crates on place without having to go to a warp with a key

✅ The crates are settable in-game.
By adding items it will be read NBT-TAG on it, Custom Name, Lore ...
❗️ I do not recommend setting them directly from config ❗️

🛑 This plugin implements also a function that makes sure that crates are given only in the world the player is executing the give crate command on
⚠️ This function is not available for CONSOLE ⚠️
(So if you run the give command from console it will be given to everyone in the whole sevrer)

🌀 In case the player, who's receiving the crate, has the inventory full, the crate will be dropped on the ground
(Also when you receive rewards from the crate, they will be dropped if the inventory is full)

Commands

/portablecrate help
/pcrate help

Permissions

Permission Description
portablecrates.command.give Allows the player to give crates
portablecrates.command.edit Allows the player to edit crates (Create/Delete Crates - Add/Remove rewards - Toggle on/off give on world - reload config files)
