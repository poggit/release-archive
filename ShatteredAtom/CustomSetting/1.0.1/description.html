INFO

Your Probably wondering what this plugin does, aren't you? Well Wonder no more for I am here to tell you. This plugin allows you to add a custom section in the settings of your server. This can be useful for displaying rules, a list of Staff, or even just to say hi.

Configuration

Now your wondering, but how do i change the message to better suit my needs? Well once again I will save you the time of looking yourself. The message is completely customize-able by going to the settings.json file in the customsetting folder and changing it there.

Extra-information

So you downloaded it now what? That is completely up to you. You can have it say whatever you want, so long as you can type it in.
