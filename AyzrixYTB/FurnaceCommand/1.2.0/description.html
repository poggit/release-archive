Furnace

Description

Furnace Command is a simple plugin that adds a command to furnace items in your hand. With this plugin, simplify the use of furnaces and allow your players to furnace their items faster.g

Command

name: furnace
description: Furnace the items in your hand
permission: furnace.command
aliases: []

command_name: "furnace"
command_description: "Furnace the items in your inventory"
command_permission: "furnace.command"

command_aliases: []

not_player: "{prefix} §cYou must be a player to use this command"
