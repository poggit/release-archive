What is this?

BlockSniper is an advanced world editing tool, based on the idea of VoxelSniper from Minecraft PC softwares. BlockSniper allows you to edit your world on a long range, with several different types and shapes. Shapes are the shapes types are being executed in. This means that every type can be executed in any shape. For more information, make sure to check the Wiki.

How does it work?

BlockSniper has several commands to edit your world. The commands can be found on the Wiki page here.

Are there permissions? Where can I find them?

A full list of permissions can be found in the plugin.yml file. It contains the most up to date permissions, so every permission available can be found there.

I love/hate BlockSniper! Where can I review this?

BlockSniper can be reviewed at the poggit release page here. Any feedback given is very welcome, and it would be very much appreciated!

What does every setting in the settings.yml mean?

The explanation of every setting in the settings.yml can be found in the in-game configuration menu accessed using /blocksniper menu. It is highly recommended to use this, rather than editing the configuration directly. If you do prefer editing the configuration file directly, please do so when the server is stopped.

Translation

BlockSniper has a multi-language system, so everybody can have a good time using the plugin. We currently have nowhere near enough translated languages though, and we need your help! It is very appreciated if you help translate, so please do so whenever you have time. The available languages can be found under resources/languages.

Development versions

Stable releases will be drafted at Releases. If you do decide to use a development version to benefit from the latest features, here's how:

  • Click the Poggit-CI button below this segment.
  • Download a phar file from the latest development build.
  • Upload your phar file to your server and restart the server.
