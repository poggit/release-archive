General

PiggyTutorials is a simple plugin to create a tutorial for your server.

How To Use

To use this plugin, do /tutorial.

Config

You can set the messages in your tutorial.

  messages:
    - "This is an example"
    - "You can have as many messages in your tutorial as you would like"

You can also set the delay between each message.

  delay:2
