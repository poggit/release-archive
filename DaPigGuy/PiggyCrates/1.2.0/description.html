General

PiggyCrates is a simple, customizable, crates plugin. It supports an unlimited amount of crate types. It also supports vanilla and custom enchants, such as PiggyCustomEnchants.

How To Use

Place a chest on top of a designated crate type block to create a crate. To open crates, you must use a crate key, obtainable with the /key [amount] [player] command.
