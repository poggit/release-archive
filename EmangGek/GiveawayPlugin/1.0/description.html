Giveaway Plugin

Create a giveaway on your server

Command List

/glist

This command is for showing all giveaways to the player Permission: giveawayplugin.list

/gcreate

This command is for creating a giveaway Permission: giveawayplugin.create

/gend

This command is for ending a giveaway Permission: giveawayplugin.end
