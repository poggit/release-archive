Function

This plugin clears your inventory if you fell out from the world and then teleport you back to the world’s spawnpoint.

Commands:

/foic - It shows the information about the plugin.

Comment:

This plugin recommended for SkyPvP servers which are using KDR plugin, because if a player fell out from the world the KDR plugin doesn’t count it as death.
