StarGate-Atlantis

This is stable and fast plugin for pmmp that allows server connect to StarGate server. StarGate protocol allows communication between servers, proxy using own packet system. You can setup StarGate server as proxy plugin and easily interact with proxy (supports Waterdog, WaterdogPE).
Growing documentation can be found here.

Features:

  • Fast TCP based socket connection between servers.
  • Custom packets implementation.
  • Moving players between servers (API).
