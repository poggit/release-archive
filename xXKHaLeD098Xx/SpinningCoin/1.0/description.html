SpinningCoin

This is a simple PMMP plugin to create a spinning coin telling players how much coins they have!

Usage

NOTE: Commands only work with OPs
Spawn the spinning coin: /spinningcoin spawn
Removing the spinning coin: stand near it and execute: /spinningcoin remove

Config

in config.yml you can edit the nametag format
