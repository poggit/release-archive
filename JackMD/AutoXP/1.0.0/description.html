A AutoXP plugin that collects all the experience without dropping any experience orb for PocketMine-MP.

Features:

  • AutoXP automatically transfers all the xp to your experience bar without dropping any.
  • Great way to reduce lag caused by Experience Orbs.

How to setup?

  • Get the .phar and drop the into your plugins folder.
  • Start the server.
  • Start mining blocks.
