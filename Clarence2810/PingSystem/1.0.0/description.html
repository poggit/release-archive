PingSystem

Advanced and Cool stuffs about player pings

Why you should use this?

  • This system is compacted into one that existed in here but this is not messy for your server files and added more advanced stuff like if player have bad ping it will change the color of player tag and you can see it too at /ping, you can also fully customised this on config like messages, ping colors, good stable and bad ping numbers etc.,
