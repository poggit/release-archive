Description

PlayerWarps, let players create their own warps for money.

Commands

/pwarp - teleport to an pwarp

/pwarp price §7- shows alls prices of an pwarp

/pwarp create - create an pwarp

/pwarp delete - delete an pwarp

/pwarp newpos - change position of an pwarp

/pwarp info - get info of an pwarp

/pwarp list - get a list of all pwarps

Config

In the config you can adjust the prices for deleting, newposing and creating a warp
