Intro

This plugin is like a 1v1 tournament, it creates an event and each round has 2 people fight eachother.

Make sure to setup the spawns and world in config before using this. Please report any issues to the github and thanks to BoomYourBang#4077 for helping me optimize a few things.

Permissions

"redrover.create" grants access to use all /rr commands.

Commands

Commands Usages
rr create Creates a tournament and makes it joinable.
rr list Lists the players in the tournament.
rr round Chooses 2 random players and puts them in the arena to fight.
The event will automatically end if you do /rr round and only one person is left.
