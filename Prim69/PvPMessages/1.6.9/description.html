This is a fully customizable plugin that allows you to set death messages each time a player kills another player.

What this plugin can do which no other plugin on poggit can, you can set the death messages in an array and each time a player dies it'll be a random death message from the ones you put. You also have the option which is enabled by default to show the killers health next to the name which would look like this: Randy was railed by xPrim69x [13.54] assuming that's how much health xPrim69x had remaining.

Please report any issues to the GitHub, I also ask that if the plugin doesn't have a feature that you would like, please don't leave a bad review, just suggest it and I might add it.
