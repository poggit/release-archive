About

This plugin allows you to spawn in a fake entity with the option of armor or no armor, it copies your skin and you can hit it around like a regular player!

Commands

Commands Usages
fakeplayer def Spawns a fake player with no armor
fakeplayer armor Spawns a fake player in full diamond armor.

Alias: /fp

Permissions

fakeplayers.spawn allows you to use the command /fakeplayer to spawn in a fake player.
