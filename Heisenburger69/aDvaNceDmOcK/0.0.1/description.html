AdvancedMock:

Mock any chat messages sent on the server

Features:

  • Give your players the ability to mock the last sent message of any player
  • Ability to toggle mock for yourself so all your messages turn into randomcase
  • Player's can also use /mockme to turn the text after the command into randomcase
  • Server admins can make the entire server chat into randomcase aNd MaKe iT lOok LiKe tHiS
  • Server admins can be made immune to mocking by setting the permission "mock.immune"

Commands:

  • /mock : Mocks the last sent message of any user. Permission: "mock.player"
  • /mockme : Changes the text into randomcase. Permission: "mock.self"
  • /mocking <on/off>: Toggles all your future messages from turning into randomcase. Permission: "mock.toggle"
  • /mockall <on/off>: Toggles mocking of the entire server chat. Permission: "mock.all"
