BurgerSellWands

Pocketmine Plugin adding Sell Wands to the game. A Sell Wand allows players to quickly sell items inside a chest by just tapping the chest! This plugin is a must have for servers that have an Economy. Players have several ways to gain money, but now with Sell Wands, they can sell the loot much, much quicker!

Sell Wands can also be used as an incentive to vote or donate to your server.

Features

  • Sell the contents of a chest by just tapping it
  • Fully customizable item name, lore and ID
  • Sell Wands can be set to have a maximum amount of uses
  • Integrates seamlessly with plugins like Skyblock or Factions
  • All Sell prices are customizable
  • /sellwand {player} {uses}: Gives {player} a Sell Wand with a max of {uses} uses
  • Set a negative usage to give wands with Unlimited uses!
  • All plugin messages are customizable

Permissions

sellwand.command: Lets a player run /sellwand
sellwand.use: Lets a player use Sell Wands
