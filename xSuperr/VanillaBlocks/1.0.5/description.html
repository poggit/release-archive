Vanilla Blocks

This plugin aims to add all blocks not included in PocketMine.
As of right now the ExtendedBlocks plugin is required to add blocks with IDs above 255.

Once PocketMine 4.0 Releases, the ExtendedBlocks plugin will no longer be
required.

Current Blocks:

  • Ancient Debris
  • Barrels
  • Basalt and Polished Basalt
  • Barriers - [/give player -161]
  • Nether Gold Ore
  • Lanterns
  • Campfire
  • Blackstone Block Variants
  • Amethyst Block [Unmapped]
  • Stripped Logs
  • Beehives
  • Bee Nests
  • Chains
  • Soul Torch
  • Soul Campfire
  • Soul Lantern
  • Soul Soil
  • Scaffolding
  • All Stairs
  • All Trapdoors
