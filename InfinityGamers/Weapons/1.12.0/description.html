Weapons

Experimental guns plugin for PocketMine.
I recommend that you only use this for playing with friends and such. The plugin is not very extensive and should not be used on large-scale servers because it can potentially have bugs or break.

Commands

  • /weapon : help command
  • /weapon guns : list guns
  • /weapon gun [player] : give a weapon
  • /weapon ammo [player] : gives a player ammo

Permissions

  • command.weapon
    • default: op
