ItemCooldowns

A plugin for Pocketmine-MP 3.0.0 and above that allows administrators to set cooldowns for consumables & throwables!

  • If you have any suggestions/ideas/questions feel free to contact me on discord at Rushil#2326
  • If you find any bugs you can report them here

Features

  • Can set cooldowns for any and all consumables & throwables!
  • Eg: Ender Pearls, Golden Apples, Speed Potions, Snowballs etc
  • You can blacklist any number of worlds, these cooldowns won't apply there!
  • Permission to bypass these cooldowns!
