EasyModeration

An all-in-one Moderation plugin for Pocketmine-MP

  • If you have any suggestions/ideas/questions/bugs go here or contact me on discord at Rushil#2326

Features

  • Many Moderation commands
  • Discord Webhook support for all commands
  • Chat Interval
  • Chat Censor

Commands & Permissions

Commands Aliases Permissions Usage
/ipban none easymoderation.ipban /ipban <address
/ipunban none easymoderation.ipunban /ipunban
/permban none easymoderation.permban /permban [reason...]
/tempban none easymoderation.tempban /tempban [reason...]
/unban none easymoderation.unban /unban
/kick none easymoderation.kick /kick [reason...]
/mute none easymoderation.mute /mute [reason...]
/unmute none easymoderation.unmute /unmute
/mutelist none easymoderation.mutelist /mutelist [players
/warn none easymoderation.warn /warn [reason...]
  • For any time argument, y -> years, mo -> months, d -> days, h -> hours, m -> minutes, s ->seconds. Eg: /tempban Ign 1y6mo9d Reason
  • Incase of mute use [inf, infinite, perm, permanent, forever] for a perm mute
  • /mutelist gives a list of all muted players on the server
