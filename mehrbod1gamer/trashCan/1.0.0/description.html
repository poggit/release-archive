Description

With this plugin operators can spawn trashcans and all players can put their trashes in trashcans inventory by clicking on them.

SetUp

1.download .phar file from poggit.

2.put .phar file in your server plugin folder.

3.get trashcan spawner item by /trashcan get command in game and you can spawn trashcan by place the skull block on ground.

4.also you can delete trashcan by /trashcan rem and clicking on it.

note

This plugin uses InvMenu.

  • You dont need to download the virion when you use phar form Poggit.

  • if you don't use phar you should use DEVirion to install InvMenu.
