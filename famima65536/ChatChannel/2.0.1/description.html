Chat Channel

This is a plugin for PocketMine-MP.
You can make 'CHAT CHANNEL' on the server.

usage

How to open a menu : you have a item sugar, and touch somewhere.
command: /chatchannel

config

default language is en(English).
you can change language to ja(Japanese).

Q&A

Q. How can I create "CHAT CHANNEL"?
A. Open the menu, and choose "Make channel".

Q. Can I join "CHAT CHANNEL"?
A. Yes. Open the menu, and choose "Choose Channel".
