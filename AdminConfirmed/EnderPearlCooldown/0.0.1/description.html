EnderPearlCooldown

A fully customizable Ender pearl cooldown.

Usage:

To change the EnderPearl cooldown timer You can either use /pearlcooldown to change the cooldown or you can edit it in the config.yml file

To change the EnderPearl cooldown message You can change it in the config.yml file and use {cooldown} to get the cooldown timer

commands

pearlcooldown: usage: /pearlcooldown permission: pearlcooldown.change description: Changes the current EnderPearl cooldown
