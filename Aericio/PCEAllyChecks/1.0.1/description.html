PCEAllyChecks

PCEAllyChecks is an extension to the PiggyCustomEnchants plugin which utilizes the AllyChecks feature introduced in v2.1.0.

Currently, the following plugins are supported:

  • FactionsPE
  • FactionsPro
  • Slapper
  • WorldGuard

PCEAllyChecks will prevent certain custom enchants from affecting your faction members/allies:

  • AutoAim
  • Blaze
  • Cactus
  • Forcefield
  • Homing Arrows
  • Lightning
  • Poisonous Cloud
  • Wither Skull

It will also prevent custom enchantments from affecting Slappers + areas protected by WorldGuard.

Requests

If you would like to request a plugin to be supported by PCEAllyChecks, please create an issue.

Denied Requests

  • Festival: Horrible API. Horrible, as in none at all.
