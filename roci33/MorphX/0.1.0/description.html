MorphX

This plugin allows you to transform yourself into an entity!

In fact, with a simple command it will be possible to transform the player who executed the command into an entity (Example: zombies, sheep, skeletons...) chosen by him

Feature:

• Simple command

• Does not generate lag

• In continuous development!

Command

Command list:

• /morph (or /m): This is the main command, to view the rest of the function use /morph help

• /morph EntityName (or /m EntityName): This command allows you to be transformed into an entity!

• /morph list (or /m list): This command allows you to view a list of entities that can be transformed into

• /morph remove (or /m remove): This command allows you to return to human

Permissions

Permissions list:

• morphx.command.morph: This permission enables all functions of the plugin a player
