SimpleBanner

This plugin allows you to generate custom banners with all the existing patterns and colors, using a simple user-friendly in game interface.

Commands

  • /banner color tag - Open a simple menu to create the banner

    Permission: simplebanner.command.banner

Color Tags

Also visible with /banner

  • black
  • dark_green
  • dark_aqua
  • dark_purple
  • orange
  • gray
  • dark_gray
  • blue
  • green
  • aqua
  • red
  • light_purple
  • yellow
  • white
