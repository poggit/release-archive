MultiVersion

Allows the connection of lower client versions to higher PocketMine-MP server versions. Your server player count dropped when Minecraft update? You should use this plugin.

  • Not a spoon/fork
    • Just use a plugin to support multi protocol without changing PMMP API.
  • Performance
    • Use asynchronous to compress and decompress packet.
  • Stable
    • Almost all packets are converted.
    • Client won't crash.
  • Scalability
    • Easy to implement future versions.

Supported Versions

  • 1.17.10 (448)
  • 1.17.30 (465)
  • 1.17.40 (471) (PMMP Default Version)
