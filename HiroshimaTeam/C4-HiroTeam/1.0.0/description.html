C4 pocketmine plugin | Plugin de C4

ENG: Plugin that allows you to use most blocks as C4. You place a block (by default, the button), it explodes after a few seconds! Very original for base looting.

PS: it explodes the adjacent obsidian blocks!

FRA: Plugin qui vous permet d'utilisé la plupart des blocs en tant que C4. Vous placer un bloc (par defaut, le bouton), elle explose après quelques secondes ! Tres original pour les pillages de base.

PS: elle explose les blocs d'obsidienne adjacent !
