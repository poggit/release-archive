About

Exchange Pocketmine OFFICIAL

[ENG] This is a PocketMine-MP (or forks) plugin which allows you to change the price of items relative to the number of items purchased according to a time ! Excellent for an interactive economy. FULL CONFIG 😁

[FRA] C'est un PocketMine-MP plugin de bourse qui permet de changer le prix des items par rapport au nombre d'item acheté selon un temps ! Excellent pour une economy interactive. FULL CONFIG 😁

  • Discord Server: 🔗 https://discord.gg/WuwsuUA

How to use

[ENG] Do /exchange and then a ExchangeUI appears so that players can sell their item according to the price of the current purse. Tip: Put the command on a slapper!

[FRA] Faite /exchange et ensuite une bourseUI apparait pour que les joueurs puissent vendre leur item selon le prix de la bourse actuelle. Astuce: Mettez la commande sur un slapper !
