WorldGuard Extension: Block Item Frame Plugin | Plugin qui permet de bloquer les cadres

FRA: Permet de bloquer les cadres dans les zones parce que WorldGuard ne le permet pas. Tres pratique pour pouvoir mettre des cadres avec des items à l'interieur sans que les joueurs puisse récuperer dedans dans les areas WorldGuard

exemple: je fais un shop protégé par WorldGuard et j'aimerai mettre des cadres sans qu'on puisse récuperer dedans. BlockItemFrame est là pour ça !

ENG: Allows you to block items frames in areas because WorldGuard does not allow it. Very practical to be able to put frames with items inside without the players being able to recover from them in the WorldGuard areas

example: I make a shop protected by WorldGuard and I would like to put frames without being able to recover them. BlockItemFrame is there for that!
