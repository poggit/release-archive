CustomFurnace pocketmine plugin | Plugin de Four Customisé

ENG: Plugin that allows you to customize and add unlimited oven recipes. Very practical to be able to Furnace any items to get what you want!

example: I Furnace a whole diamond armor to get diamond ingots

FRA: Plugin qui vous permet de personnaliser et d'ajouter illimite des recettes de fours. Tres pratique pouvoir faire cuire n'importe quel items pour obtenir ce que vous voulez !

exemple: je fais cuire toute une armure en diamant pour obtenir des lingots de diamants
