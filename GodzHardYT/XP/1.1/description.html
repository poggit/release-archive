XP

This plugin allows you to add or remove xp!

In fact, with a simple command you can add or remove as much xp as you want to a specific player! (example: / xp add GodzHardYT 120 or / xp remove GodzHardYT 20)

Features

• Simple command • It does not cause lag • The plugin is 100% configurable

Info

Commands •/xp add:remove

Permissions The preconfigured permission is "xp.command.use" but it is possible to change it from the config.
