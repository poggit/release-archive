Overview

This plugin brings bountys to MCPE, it does depend on EconomyAPI (only for now) so it will only work if you have a production release of EconomyAPI (can be found over at Poggit)

Usage:

  • /bounty credits/version/help
  • /bounty new player amount
  • /bounty add player amount
  • /bounty rem player
  • /bounty leaderboard
  • /bounty list page

Bugs:

  • None at the moment.
