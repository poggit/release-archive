XGTAntiXRay

Description

This is a PocketMine Plugin.

This plugin notifies the staff when someone breaks an ore

How to install

  1. Install plugin

  2. Stop/start server

  3. Edit config

  4. Restart server

  5. Have FUN!

Features

  • [X] Config

  • [X] Costom Warnings(Place/Break)

Permissions

Break

xgtantixray.break

Place

xgtantixray.place

Other
