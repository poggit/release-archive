AntiBlock

Block people from placing specified blocks, to prevent griefing or other stuff.

How to use this plugin?

You have to start the plugin, then edit the config in path/to/server/plugin_data/AntiBlock/config.yml and edit it.

Config Options

prefix: Here you can set the prefix for the plugin

reloaded: This is the message that a player will get if he executes the command /antiblockreload

message-player: This is a Boolean Value. If you will set this to false the player will receive no message if he places a blocked block.

place-message: This is the message when a player places a blocked plugin receive.

blocks: This is an Array of the blocked blocks. Some examples for blocks: TNT, DIAMOND_BLOCK, DIRT

Commands

There is 1 command: /antiblockreload, it reloads the config from the plugin.

Permissions

There are 2 permissions: antiblock.bypass and antiblock.reload.

antiblock.bypass will bypass the block check and antiblock.reload is the permission to execute the command /antiblockreload
