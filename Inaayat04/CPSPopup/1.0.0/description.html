CPSPopup

  • A pocketmine plugin shows the cps on their popup/tip
  • Like Versai/Valea CPS
  • You will have 2 choice in config.yml
  • CPSTask or CPSListener.
  • I would recommend the CPSListener.

How to Install?

  • Put the plugin to you're /plugins folder.
  • Restart you're server.
  • and done Enjoy.
