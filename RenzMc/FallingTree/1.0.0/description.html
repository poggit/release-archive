FallingTree - Simplify Tree Cutting

FallingTree is a plugin designed to make tree cutting faster and more efficient for players. By chopping just one log block, the entire tree will fall down. This feature is perfect for survival servers that want to enhance the player experience with a rank or permission system.

Features

  • Efficient Tree Cutting: Cut one log block, and the entire tree will fall. This greatly speeds up the tree-cutting process and reduces the time needed for players to gather wood.

  • Permission-Based: The plugin is designed so that only players with a specific permission can use this feature. This is ideal for servers with a rank system. The required permission is fallingtree.use.

  • Support for All Wood Types: With the latest update, the plugin now supports all types of wood in Minecraft, including Acacia Wood, Dark Oak, and other wood types!

New Update

  • Added Support for Acacia Wood: In this latest update, the plugin now supports all wood types, including Acacia Wood and other previously unsupported types.
  • Improved Performance: Tree cutting has been optimized for faster and more responsive performance, especially on servers with many active players.

Usage

  1. Permission: Ensure that the players who will use this feature have the fallingtree.use permission. You can add this permission using a permission manager plugin or manually in the server's permission file.

  2. How to Use: Once players have the permission, they just need to chop one log block at the base of the tree, and the entire tree will fall and break.

Installation

  1. Download: Download the plugin from Poggit.
  2. Install: Place the .phar file in the plugins folder of your PocketMine-MP server.
  3. Restart: After that, restart your server, and the plugin will automatically activate.

Future Plans

  • Custom Tree Support: Planned support for custom or modified trees in future updates.
  • Configurable Settings: Adding configurable options to adjust the tree-falling mechanics, including delay and the number of dropped logs.
