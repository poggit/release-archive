Description

Real-time chat translation system where users can set their language via /language and see all their chat in their preferential language. This plugin uses LibreTranslate which is a server application that looks like Google Translate but you can host it in your own machine.

Prerequisites

  • An internet connection.
  • You will need the LibreTranslate server running on your machine, you can see the instructions at https://github.com/LibreTranslate/LibreTranslate.

Command

  • Players can change their language with /lang or /language (if there is no input, the player will get their active language and also the list of available languages they can choose).
